# MUSE

MUSE is a multi-language mathematical software suite for research and experimentation in computational number theory, lattice algorithms, and continued fractions. It provides C++ libraries, test benches, and applications, as well as Python and .NET interfaces for data analysis and visualization.

## Repository Structure

- **CPPLibrary/**: Core C++ library implementing algorithms for continued fractions, lattice reduction (LLL), rational numbers, matrix operations, and more.
- **CPP/**: C++ command-line application for running continued fraction expansions and exporting results as JSON.
- **CPPTestBench/**: C++ test bench for running and validating library algorithms.
- **ProjectBosmaSmeets/**: C++ application for generating Dirichlet data and Bosma-Smeets plots, with JSON serialization for downstream analysis.
- **ProjectBSPlots/**: Python project for plotting and analyzing data generated by ProjectBosmaSmeets.
- **TestAPP/**: .NET Core application for testing and consuming the C++ library via P/Invoke.
- **PythonPort/**: Python scripts for reading and processing JSON data output from the C++ applications.

## Key Features

- **Continued Fraction Expansion**: Compute continued fraction representations and convergents for real numbers.
- **LLL Lattice Reduction**: Perform lattice basis reduction using the LLL algorithm.
- **Dirichlet Data Generation**: Generate and analyze Dirichlet coefficients for research in Diophantine approximation.
- **Cross-language Interoperability**: Export results as JSON for use in Python and .NET environments.
- **Visualization**: Plot and analyze mathematical data using Python (matplotlib).

## Building the Project

### Prerequisites

- Visual Studio 2019 or later (with C++ support)
- CMake (optional, for custom builds)
- Python 3.8+ (for ProjectBSPlots and PythonPort)
- .NET Core 3.1+ (for TestAPP)

### Build Steps

1. Open `MUSE.sln` in Visual Studio.
2. Build the solution. This will compile:
   - `CPPLibrary` as a DLL
   - `CPP`, `CPPTestBench`, and `ProjectBosmaSmeets` as C++ applications
   - `TestAPP` as a .NET Core application

3. (Optional) Set up a Python environment and install required packages (e.g., `numpy`, `matplotlib`).
